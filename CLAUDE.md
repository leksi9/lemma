# Лемма

Доска для уроков (Windows-приложение на pywebview + одна HTML-страница `doska.html`).

## Коммиты
- Не добавлять строку `Claude-Session: ...` в сообщения коммитов и описания PR. Строку `Co-Authored-By` оставлять.
- Первый абзац сообщения коммита становится описанием версии («Что нового» в Лемме) — писать его по-русски, понятно для пользователя.

## Сборка
- Любой пуш в `main` (кроме README, docs, CLAUDE.md, .github) собирает установщик и выпускает новую версию через GitHub Actions; Лемма находит её автообновлением.
- После правки `doska.html` выполнить `python build.py doska.html`, чтобы обновить `app/index.html`.
