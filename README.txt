ДОСКА — приложение для Windows
==============================

Первый раз (один раз и навсегда):
  1. Двойной клик по build_exe.bat. Нужен Python 3.12 (python.org).
  2. Через 1–2 минуты откроется папка dist\Doska с Doska.exe.
     Папку dist\Doska можно перенести куда угодно.
  3. Правый клик по Doska.exe → «Отправить» → «Рабочий стол (создать ярлык)».

Дальше просто запускайте Doska.exe. Пересобирать его не нужно.

Как ставить обновления (новые функции доски):
  Вся доска — это один файл app\index.html рядом с Doska.exe.
  Когда приходит новый архив:
    • распакуйте его и запустите update.bat — он сам скопирует новую версию
      (если Doska.exe в другом месте, скрипт спросит папку — перетащите её в окно);
    • или вручную замените app\index.html рядом с Doska.exe.
  Доски при обновлении не пропадают: они хранятся отдельно, в %APPDATA%\Doska.
  Пересобирать exe придётся только если поменяется doska.py (я об этом скажу).

Без сборки (если нужен быстрый запуск через Python): run.bat.

Резервная копия досок: меню «…» → «Сохранить доску в файл» (.doska).

Если что-то не так:
  • «Неизвестный издатель» при запуске — exe не подписан сертификатом.
    «Подробнее» → «Выполнить в любом случае».
  • pywebview не ставится на Python 3.14+ — поставьте Python 3.12.
  • Окно отладки: python doska.py --debug
